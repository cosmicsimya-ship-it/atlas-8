## Preface

This document defines the **operating language** of ATLAS.

It is not a website style guide.  
It is not a marketing brand book.  
It is the foundation that makes ATLAS recognizable as one intelligence across every future interface.

**Rule:** No production UI ships until this system is approved.  
**Rule:** No temporary UI. No one-off components. Everything inherits from this language.

**Quality bar:** Compare every decision to the rigor of Apple HIG and premium AI products — then invent something original. Do not imitate.

# 0.1 ATLAS Fingerprint (logo-free recognition)

If the wordmark is removed, ATLAS must still be identifiable by this **Recognition Triad**:

### A. Silhouette — Register Core

ATLAS is **not** a glowing orb (generic AI).  
ATLAS is a **Register**: 3–5 translucent analytical planes (discs / rings / sheets) at slight depth offsets.

| State | Geometry |
|-------|----------|
| Idle | Planes breathe; slightly out of perfect alignment |
| Attentive | Outer planes stabilize |
| Thinking | Micro-drift increases; planes seek alignment |
| Insight / ready | Planes snap into register; a thin **cyan seam** flashes along the alignment edge |

**Memorable after 30 seconds:** “stacked glass planes that lock into a seam of light.”

### B. Material — Smoked instrument glass

- Ultra-low white fill (3–6%)  
- Cool steel hairlines (never warm)  
- Specular only on top edge  
- **Seam light** (cyan, 1px optical) appears only when something is *in register* — focus, ready, insight  

### C. Rhythm — 5-second intelligence breath

- Core breath cycle: **5.0s** ease-in-out (signature tempo)  
- Neural field drift: **16s**  
- UI micro: 180–220ms  

Same triad maps to voice LED grammar, AR spatial anchor, and hardware glow.

# 1. Brand DNA

## 1.1 Core philosophy

**ATLAS is a living intelligence.**

Users do not visit ATLAS.  
Users enter ATLAS.

The product is not a brochure that explains an AI.  
The product *is* the AI — calm, precise, spatially present.

ATLAS does not perform mysticism.  
ATLAS does not sell fortune.  
ATLAS **registers layers** — bringing separate systems into readable alignment.

**Scientific Cosmic** worldview:

- Cosmic = scale, depth, void, quiet awe  
- Scientific = method, clarity, measurable signal, no occult theater  

**Product metaphor:** *Register* — optical / analytical alignment of planes.  
This metaphor is exclusive to ATLAS and drives Core, motion, and trust UI.

## 1.2 Personality

| Trait | Expression | Anti-expression |
|-------|------------|-----------------|
| Intelligent | Precise language, layered thinking, visible method | Vague prophecy, empty “genius” glow |
| Calm | Breath, space, soft motion | Urgency, badges, noise |
| Companion | Present, patient, conversational | Chatbot chirpiness |
| Precise | Clean geometry, exact states | Soft-focus spiritual mush |
| Curious | Invites inquiry | Dictates fate |
| Restrained | One idea per surface | Feature grids, roadmap walls |

**Voice:** Clear. Sparse. Adult. Never theatrical.

## 1.3 Emotional tone

**Evoke:** Trust · Calm · Intelligence · Agency · Quiet wonder  

**Avoid:** Mystical enchantment · FOMO · SaaS cheer · Toy AI · Persuasion theater  

## 1.4 Brand principles

1. **Presence over pages** — Rooms in one OS, not webpages.  
2. **Register over spectacle** — Alignment is the drama; glow is not.  
3. **Invisible complexity** — Power backstage; surface clear.  
4. **Trust through clarity** — Method when needed; never theatrical.  
5. **One signal at a time** — Ruthless hierarchy (Signal Budget).  
6. **Alive, not loud** — Motion = life; decoration = distrust.  
7. **Cross-surface sameness** — Same triad everywhere.  
8. **User owns the conclusion** — ATLAS clarifies; never sentences.

## 1.5 User perception goals

| Time | Perception |
|------|------------|
| 0–5s | “I entered an intelligent system.” |
| ≤30s | “I would recognize this presence again.” |
| 5–20s | “I want to speak to it.” |
| First chat | “Reasoning companion — not a chatbot.” |
| 5 years | “Same ATLAS — any device.” |

# 2. Visual Language

## 2.1 Color philosophy

ATLAS is **ice-forward**, not **blue-forward**.

Most AI products lead with saturated brand blue. That is banned as a default accent.

| Role | Color family | Why |
|------|--------------|-----|
| Field | Void / space | Thought lives in depth |
| Matter | Ice white | Human-readable content |
| Structure | Desaturated steel blue | Intent without SaaS blue |
| Life | Soft cyan (rare, bright) | Only for aliveness / focus / seam |
| Align | Cyan seam | Only when something registers |

**Forbidden**

- Gold / bronze / amber UI  
- Orange / brown systems  
- Purple fantasy / neon gradients  
- Cream editorial / broadsheet  
- Rainbow status walls  
- **Tailwind-default blues as brand** (`#3B82F6`, `#2563EB`, etc.)  
- Magenta/violet “AI glow”  

## 2.2 Color tokens

### Foundations

| Token | Value | Why |
|-------|-------|-----|
| `void` | `#000101` | Absolute depth |
| `space` | `#03040A` | Primary canvas |
| `midnight` | `#0A121C` | Elevated plane |
| `navy` | `#0E1824` | Inset wells |
| `ink` | `#E8ECF2` | Primary text (Ice) |
| `ink-soft` | `#C5CCD6` | Secondary emphasis |
| `mute` | `#8B93A3` | Captions |
| `mute-dim` | `#5C6573` | Disabled |

### Signal (proprietary — not stock SaaS blue)

| Token | Value | Why |
|-------|-------|-----|
| `steel` | `#7A92B0` | Structural accent (desaturated; memorable as instrument metal) |
| `steel-deep` | `#4A5F78` | Pressed / active structure |
| `cyan` | `#8EEAFA` | Life / focus / seam (slightly iced cyan, not neon candy) |
| `cyan-soft` | `rgba(142, 234, 250, 0.12)` | Diffusion only |
| `seam` | `rgba(142, 234, 250, 0.85)` | 1px alignment light — ATLAS signature |
| `ice-cta` | `#E8ECF2` | Primary button fill |

**Removed from v0.1:** `electric` `#3B82F6` and `electric-deep` `#1D4ED8` (generic AI SaaS).

### Glass & edge

| Token | Value | Why |
|-------|-------|-----|
| `glass` | `rgba(255, 255, 255, 0.035)` | Quieter than typical glassmorphism |
| `glass-raised` | `rgba(255, 255, 255, 0.06)` | Hover |
| `border` | `rgba(170, 198, 220, 0.11)` | Steel hairline |
| `border-strong` | `rgba(170, 198, 220, 0.22)` | Focused containers |
| `highlight` | `rgba(255, 255, 255, 0.45)` | Top specular |

### Semantic (sparse)

| Token | Value | Use |
|-------|-------|-----|
| `success` | `#34D399` | Confirmed only |
| `warning` | `#E7C56A` | Caution only (desaturated; not brand gold UI) |
| `danger` | `#F87171` | Error only |

## 2.3 Typography

| Role | Family | Why |
|------|--------|-----|
| Brand / titles | **Syne** | Geometric OS presence |
| Body | **Manrope** | Calm readability |
| Data / IDs | **JetBrains Mono** | Machine precision only |

**Retired:** Cormorant Garamond / decorative serif.

### Scale

| Token | Size | Weight | Tracking | Use |
|-------|------|--------|----------|-----|
| `display` | 48–72 | 600–700 | −0.03em | Brand / entrance |
| `title` | 28–40 | 600 | −0.02em | Surface titles |
| `headline` | 20–24 | 600 | −0.015em | Panels |
| `body` | 15–17 | 400–500 | 0 | Conversation |
| `caption` | 12–13 | 500 | 0.02em | Meta |
| `micro` | 11 | 600 | 0.16em | System labels (rare) |

**Brand mark rule:** Syne, wide tracking (~0.28em), ice metal gradient (steel→ice), never gold, never cyan fill on the word.

## 2.4 Spatial system — Clarity Corridor

Do **not** default to centered SaaS marketing layouts.

**Clarity Corridor:** Primary readable matter occupies a calm vertical mass (typically left or center-left).  
Atmosphere + Register Core occupy the remaining field.

| Context | Measure | Margin |
|---------|---------|--------|
| Entrance corridor | max 36rem copy/field | 20–80 by breakpoint |
| Conversation | 720–760px column | Centered in void |
| Knowledge / Memory | 960–1120px | Wider instruments |
| Voice | Core-dominant; text minimal | — |

**Silence Ratio (Entrance):** ≥ **55%** of first viewport is atmosphere / Core / void — not UI chrome or copy.

**Why:** Crowded first viewports feel like websites. Silence feels like a system.

## 2.5 Spacing scale

Base **4**: `4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 · 128`

Prefer jumping a spacing step over adding dividers.

## 2.6 Radius

| Token | Value | Use |
|-------|-------|------|
| `radius-xs` | 6 | Dense controls |
| `radius-sm` | 10 | Compact inputs |
| `radius-md` | 14 | Non-pill buttons |
| `radius-lg` | 20 | Panels |
| `radius-xl` | 28 | Stages |
| `radius-pill` | 9999 | Primary CTA only |

## 2.7 Elevation · Shadows · Blur

| Level | Use |
|-------|-----|
| `e0` | Void canvas |
| `e1` | Glass dock (nav, composer) |
| `e2` | Float panels / bubbles |
| `e3` | Register Core / stage |
| `e4` | Dialog over dimmed void |

| Shadow | Value |
|--------|-------|
| `shadow-float` | `0 8px 32px rgba(0,0,0,0.45)` |
| `shadow-stage` | `0 16px 64px rgba(0,0,0,0.55)` |
| `shadow-inset` | `inset 0 1px 0 rgba(255,255,255,0.45)` |

| Blur | Value | Use |
|------|-------|-----|
| `blur-sm` | 12 | Light glass |
| `blur-md` | 20 | Panels |
| `blur-lg` | 28 | Nav / overlay |
| `blur-atmosphere` | 48–80 | Field diffusion only |

**Luminance cap:** No full-screen glow wash. Ambient diffusion opacity ≤ **0.08**. Seam is exempt (local, 1px).

## 2.8 Glass rules

1. Fill `glass` / `glass-raised`  
2. Blur `blur-md|lg`  
3. Hairline `border`  
4. Top specular only  
5. `cyan-soft` **only** for focused / thinking / seam-adjacent states  

**Anti-generic glass:** Avoid high-opacity frosted white “widget stacks.” ATLAS glass stays nearly invisible so the Register field remains the star.

## 2.9 Lighting rules

| Light | Rule |
|-------|------|
| Ambient | ≤ 8% opacity; cool only |
| Core | Soft radial; never spotlighting UI |
| Seam | Appears on alignment / ready / focus |
| Focus | Cyan ring 2px + optional soft field |
| Error | Local danger — never global wash |

# 3. Motion Language

**Axiom:** Motion communicates intelligence. Else delete.

## 3.1 Timing

| Token | Duration | Meaning |
|-------|----------|---------|
| `motion-micro` | 120–160ms | Ticks |
| `motion-ui` | 180–220ms | Hover / press |
| `motion-enter` | 280–420ms | Mount |
| `motion-page` | 350ms | Surface change |
| `motion-breath` | **5.0s** | Signature life |
| `motion-neural` | **16s** | Field drift |
| `motion-register` | 600–900ms | Planes → seam alignment |
| `motion-think` | 2.2s cycle | Thinking |

## 3.2 Ambient (purpose-bound)

| Element | Purpose | If removed, lose… |
|---------|---------|-------------------|
| Particle field (sparse) | Depth alive | Sense of environment |
| Plane drift | Thinking field | Register metaphor |
| Core breath 5s | System awake | Living presence |

**Atmosphere Budget:** ≤ 2 ambient systems visible at once (e.g. breath + one field). Particles **or** neural drift — not both at full strength.

## 3.3 Hover · Scroll · Load

- Hover: −1px lift, border strengthen, no bounce, scale ≤ 1.02  
- Scroll: atmosphere parallax ≤ 8%; text never parallax; enter-once fades  
- Load: StatusPulse + label; skeleton glass; no logo spinners  

## 3.4 AI thinking & response

| Phase | Motion |
|-------|--------|
| Received | Composer micro-acknowledge |
| Thinking | Register drift ↑; ThinkingIndicator; optional seam seeking |
| Streaming | Calm cascade (not frantic typewriter) |
| Settled | `motion-register` → seam whisper → idle breath |

Conversation transitions keep the shell; sheets rise from depth; void dims behind `e4`.

**Forbidden:** Confetti, shimmer sweeps, orb spin, gold glitter, purple pulse storms, particle explosions.

# 4. Interaction Language

## 4.1 Feel

| Quality | Rule |
|---------|------|
| Trust | Clear states; method available; no dark patterns |
| Calm | No urgency theater; empty states invite |
| Intelligence | Thinking visible; answers structured |
| Precision | Named states; exact hit targets |
| Curiosity | Bridges to layers/memory without maze |

## 4.2 Signal Budget (cognitive load)

On any primary view, simultaneously allow at most:

1. **One** primary action (or one conversation field as the action)  
2. **One** living presence (Register Core or reduced ThinkingIndicator)  
3. **One** status whisper (StatusPulse / caption)  

Everything else is progressive disclosure.

## 4.3 Anti-noise

- No pill clusters, stat strips, roadmap chip walls  
- No multi-CTA hero stacks  
- No badge fireworks  
- If removing a visual doesn’t hurt understanding, remove it  

## 4.4 Conversation is the verb

Entrance field → Conversation composer is the **same component family**.  
Knowledge / Memory / Reasoning always offer a short path back to speak with ATLAS.

# 5. AI Core Identity — Register Core

## 5.1 Definition

ATLAS presence = **Register Core**  
A stack of translucent analytical planes that seek alignment.

**Not:** chatbot bubble · robot avatar · crystal ball · single neon orb · sacred geometry logo

## 5.2 Energy · Light · Geometry · Breath · Neural

| Dimension | Rule |
|-----------|------|
| Energy | Cool, low amplitude; rises only in think/align |
| Light | Soft radial + rare seam; never saturates UI |
| Geometry | 3–5 planes/rings; thin strokes; depth offsets |

|-------|--------|------|--------|

| Listen | Stabilize | Dim possible | Calm |

| Error | Contract | Off | Slow / muted |

## 5.4 Placement by surface

| Surface | Scale |
|---------|-------|

# 6. Product Architecture

## 6.1 Surfaces

| Surface | Job | Verb |
|---------|-----|------|
| **Entrance** | Enter the intelligence | Speak |
| **Conversation** | Think with ATLAS | Speak / listen |
| **Knowledge** | Instruments / layers | Explore |
| **Memory** | Continuity | Recall |
| **Reasoning** | Cognition on demand | Inspect |
| **Settings** | Trust controls | Configure |
| **Voice** | Core-forward | Speak / pause |

## 6.2 Entrance ≠ website

**Entrance (first viewport) must include only:**

- ATLAS mark  
- Register Core  
- One short line (≤ ~12 words)  
- AtlasField (conversation)  
- Optional quiet secondary (text link, not competing CTA)  
- Atmosphere within Atmosphere Budget  

**Forbidden on Entrance:** feature grids, pricing, roadmap status, long essays, footer farms, “how it works” marketing steps, **capability / feature catalogs**.

**Capability disclosure:** Capabilities are **not** listed on the landing page. Journey is connect → speak → discover. Rings unlock inside conversation via progressive disclosure (`CapabilityDiscovery`). Never dump the full map.

### Trust Depth (optional, below fold)

If more content exists, it is **Trust Depth** — not marketing:

- How ATLAS thinks (method, 4 beats max)  
- What is calculated vs interpreted  
- Principles (user owns conclusion)  

Trust Depth uses the same OS chrome. It must never feel like a landing page template.

## 6.3 Shared shell

Void · Atmosphere · Glass nav · StatusPulse · path to Conversation · tokens · Register DNA

# 8. Trust Grammar

Trust is a **visual system**, not a slogan.

| Pattern | Rule |
|---------|------|
| Provenance | Analytical claims can show source/method on demand |
| Calculated vs interpreted | Always separable visually (`TrustLabel`) |
| No persuasion chrome | No urgency, fake scarcity, gamification |
| Thinking honesty | Show thinking; don’t fake instant omniscience |
| Error humility | Plain language; no mystical cover |
| User agency | Final CTA is continue/decide — not “accept fate” |

# 9. Accessibility

| Area | Standard |
|------|----------|
| Reduced motion | Stop loops; static Register still premium; think becomes labeled static |
| Contrast | Body ≥ 7:1; essential mute ≥ 4.5:1 |
| Focus | Cyan 2px ring, offset 3; never naked `outline: none` |
| Keyboard | Nav → Field → Primary; trap in dialogs; Esc closes |
| Touch | ≥ 44×44 |
| Screen readers | Landmarks; `aria-live` for thinking; Core `aria-hidden` if decorative |
