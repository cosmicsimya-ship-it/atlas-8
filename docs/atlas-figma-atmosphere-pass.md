## 1. Visual Audit

### Landing Hero (Desktop)
| Observation | Impact |
|-------------|--------|
| Root frame is void, but **Nav / Hero / WhatIs have opaque white fills** | Page reads as a white SaaS site |
| Atmosphere is a short band with a single ellipse | Core feels like a footer graphic, not presence |
| Hero is text-stack only; Core is below the fold of attention | First 5s = marketing copy, not intelligence |
| Long body line full-bleed width | Noise; weak hierarchy |
| CTA secondary uses dark fill competing with void | Hierarchy muddled |
| Cormorant retired (good); Syne hero present | Type direction OK |

### Chat Presence (Desktop)
| Observation | Impact |
|-------------|--------|
| **Thread frame is solid white** | Classic chatbot / messenger panel |
| User bubble bright electric blue | SaaS chat kit |
| Dense sidebar nav (7 items + dots) | Dashboard OS, not living room |
| Large “Sohbet” title | App chrome, not presence |
| Composer OK but sits under white void | Disconnected from atmosphere |
| No idle presence before messages | Screen feels empty-app, not awake system |

### Premium atmosphere
- Darkness on Product is better than Marketing’s accidental white layers  
- Blue used as bubble paint = decoration, not intelligence  
- Glass language broken by white slabs

## 3. Final Improvements (this pass)

### Landing Hero
- Strip white fills → transparent over void  
- Nav → quiet glass (hairline + low white)  
- Hero: tighten measure, increase vertical breath, quieter body  
- Primary CTA = ice pill; secondary = ghost  
- Rebuild Atmosphere as **Register Core**: nested rings, cyan seam glow, luxurious dark field  
- Reduce WhatIs visual weight (same content, calmer surface)

### Chat Presence
- Thread → transparent / soft glass, not white  
- User bubble → ice/glass density (not electric paint)  
- Atlas bubble → softer elevated glass  
- Add idle presence whisper (status pulse + short line)  
- Soften title; more pad / gap rhythm  
- Composer glass dock; sidebar quieter (no layout redesign)

### Consistency
- Radius: panels 20, composer 16–20, bubbles 16–20, primary pill  
- Shadows: soft void only; cyan glow only on Core / focus  
- Same ice / steel / cyan language
